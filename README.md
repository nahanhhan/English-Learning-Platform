# 英语学习平台（个人本地版）

针对 **大学英语六级** 与 **考研英语（二）** 的个人英语学习平台：真题翻译 / 作文 AI 批改 + 单词短语间隔重复记忆 + 学习数据统计。所有数据保存在本机。

## 功能

| 模块 | 说明 |
|---|---|
| 📊 学习概览 | 连续打卡、今日任务、成绩趋势折线图、词书进度、最近练习 |
| 🔤 翻译练习 | 六级汉译英 38 套 + 考研英语二英译汉 7 年真题；AI 逐处批析、优化译文、关键表达点拨；支持自由练习 |
| 💬 短句翻译 | 独立中译英板块，30 道六级题材强化模拟题；逐句批改、保留重译版本、跨日期复习及表达收藏 |
| ✍️ 写作练习 | 六级短文写作 / 考研应用文 / 图表作文（清晰重绘、放大与原卷对照）；分数档、逐段点评、词汇升级、润色版与参考范文 |
| 📖 背单词 | 六级核心 5407 词 / 考研核心 4801 词（ECDICT 词库），卡片式 SM-2 间隔重复、每日新词配额、四选一测验、词表浏览、自定义添加 |
| 🔗 背短语 | 442 条考试高频短语，与单词同样的学习/测验/浏览体验 |
| 📚 课内生词和短语 | 按课文/单元分组，单词与短语均先选释义再拼写，美式发音、错题专项和自动保存进度；支持粘贴、PDF/Word 预览导入 |
| 📝 平时单词短语积累 | 独立记录日常词汇，复用课内学习与答题模式；已整理 English_notes.docx 中 41 个单词、9 个短语 |
| ⚙️ 设置 | Anthropic 官方 / DeepSeek 官方 / OpenCode Go 订阅 / 智谱 / 自定义兼容服务；推理模式与强度、模型刷新、连接测试和学习偏好 |

## 快速开始

首次使用（需已安装 Python 3.10+ 和 Node.js 18+）：

```
双击 setup.bat        # 创建虚拟环境、安装依赖、构建前端（约 2-5 分钟）
```

以后每次使用：

```
双击 start.bat        # 自动打开浏览器 http://127.0.0.1:8930
```

首次启动会自动导入题库（97 题）与词库（10650 词条），数据落在 `backend/data/app.db`。

## 启用 AI 批改

1. 打开「设置」→「AI 批改服务商」→ 添加；
2. 可点击「Anthropic 官方」「DeepSeek 官方」「OpenCode Go 订阅」「智谱 GLM」快速填充，填入对应服务的 API Key；
3. 点「测试」验证连通，设为默认；
4. 未配置 Key 时可在设置中开启「模拟批改」体验完整流程。

支持任何 OpenAI 兼容服务：填写 Base URL + 模型名 + Key 即可。Key 仅保存在本地数据库。

每条「服务＋模型」分别保存推理模式和强度，支持保存同一服务的多条模型配置。推理可选择跟随模型默认、开启或关闭；强制推理模型不能关闭，未知能力使用模型默认，关闭后不发送强度参数。DeepSeek 官方支持低、高、最高；其他模型只展示已核实或模型目录声明的档位。保存后可刷新模型列表，失败时保留原配置。真题和短句练习均可临时选择已保存配置，不改变全局默认。

Go 使用独立订阅地址，兼容既有 Go 地址，不自动转到按量接口。连接测试和批改共用请求构造，携带平台自己的 `User-Agent` 和每次独立练习的 `x-opencode-session`，同次练习的修改、重试沿用标识。在线目录显示支持 Chat Completions 或 Messages 的模型；选择 Claude 时自动使用 Go 的 Messages 接口，原订阅密钥和会话保持不变，无需重新创建已有配置。暂不支持仅提供 Responses 或 Google 专用接口的模型。[Go 官方说明](https://opencode.ai/v2/docs/console/go/)规定主要面向编码代理；翻译用途、账户权限、额度和超额设置需按服务规定核对，请求头通过不代表订阅必然可用。[DeepSeek 推理说明](https://api-docs.deepseek.com/guides/thinking_mode/)可查看具体参数。

「Anthropic 官方」是独立入口，使用官方地址和官方 API 密钥，与 Go 订阅分别保存。默认提供 Claude Haiku 5.5，可选择其他 Claude 或刷新可用模型；Haiku 5.5 支持推理开关及低、中、高、更高、最高五档强度。其他 Claude 根据已核对信息或官方模型目录显示能力，无法完全关闭的模型不提供关闭选项，关闭推理时不发送强度。新 Claude 使用自适应推理和 `output_config.effort`，旧模型使用其支持的传统思考预算。只提取正文用于批改，思考内容不会当作批改结果。[Claude 官方推理说明](https://platform.claude.com/docs/en/build-with-claude/thinking)和[强度说明](https://platform.claude.com/docs/en/build-with-claude/effort)可供核对。

## 短句翻译

左侧进入「短句翻译」（`/short-translation`），默认随机抽取未完成题目，也可按主题从题库选题。首批 30 道原创模拟题，每题 1–3 句，文化、历史、经济与城乡、社会民生、教育科技、环境发展各 5 题；1、2、3 句题各 10 道。题目依据六级考纲题材设计并适度强化结构、逻辑与表达要求，不标作官方真题。参考译文、必译信息、训练重点、来源和批次保存在 `backend/data/short_translations.json`，以稳定题号增量加入，保留旧题和学习记录。

整段输入后一次提交，不计时、不限时；草稿自动保存在当前浏览器，答前不展示提示或参考。15 分制反馈包含整体评价、逐句点评、真正错误与可优化表达、关键表达、在自己译文上修改的版本及题库参考译文，认可合理的不同译法和合并、拆分句子。修改再提交会保留首答和历次版本，并比较已解决及仍存在的问题。失败时作答保留，可手动重试或选择其他配置，不自动跨服务调用。

每次独立练习的首答低于 12 分自动加入复习清单，也可手动加入或移出。三个不同北京时间日期连续独立复习达到 12 分后标为已巩固并移出；同日最多累计一次达标，即时修改不计次，独立复习低分清零。完成题量、首次首答均分、最近作答成绩与历史单独统计，不混入真题成绩。模拟批改明确标示且不计完成、分数统计或巩固。

批改中的表达可点击「加入平时积累」，先核对英文、释义、类型与分组再确认。保留原题来源，积累库中同类型重复词条跨组跳过，已有词条及学习进度不覆盖。后续补题通过聊天提出需求后增量更新，应用内不自动生成题目。

## 真题核对与清晰图表

已对照本地原卷核对 97 道翻译及作文题，修正缺句、错配附录、页码和其他考试部分混入、英文空格与段落等问题。启动时按原题身份增量更正，保留题目 ID、练习次数、已提交作答及批改快照。2019.12 六级第 2 套作文因原 PDF 缺少正文，保留既有人工补录及原因提示。

10 张图表提供矢量清晰版，点击「放大图表」可放大，点击「查看原卷图表」可与原始裁图对照。按原题保留类别顺序、单位、年份、坐标和数字精度，不增加原题未标出的数字标签。数据与来源记录在 `backend/data/chart_redraws.json`；[逐题核对记录](docs/question-audit-2026-10-21.md)和[图表核对记录](docs/chart-redraw-2026-10-21.md)可供复查。

## 自然发音与音量

所有单词、短语、错题专项、测验和词表共用自然女声：美式为 Jenny，英式按钮为 Sonia，语速略慢（-5%），音高保持原样。每个词条完整生成，使用 [edge-tts](https://github.com/rany2/edge-tts)，无需 API Key。

朗读前会把 `sb` / `sth` 展开为 `somebody` / `something`，保留所有格，斜杠读作 `or`，括号内文字正常读出。例如 `have / get a shot at (doing) sth` 读作 “have or get a shot at doing something”。页面、词库和拼写答案保持原样。

首次生成需要联网，完整 MP3 会自动保存到 `backend/data/speech-cache/`，重启后仍可复用，已有缓存断网也能播放。未缓存且生成失败时显示「重试发音」，答题可以继续；不会切换电脑自带声音。更换发音、切题和离开页面会取消旧声音，避免迟到播放。设置页「学习偏好 → 自然发音 → 试听」可试听含缩写的完整短语。

背单词、背短语和课内词汇页面上方均可调整发音音量，默认 35%，支持静音，自动记住当前浏览器的设置；设置页也可调节。学习区采用紧凑排版，宽屏四个选项分两列显示，小窗口自动变为单列。

## 课内生词和短语

所有单词在英文旁显示词性（如 `n.`、`vt.`、`adj.`），鼠标移到标签上可查看中文说明；学习、拼写、答题结果、测验、错题本及词表均支持。词性来自词条释义和随应用分发的本地词库，多词性一并保留。现有六级、考研与课内单词全部覆盖；新添加的未知词显示「词性待补充」，添加或导入时可在释义中注明，例如 `n. 名词释义；v. 动词释义`。已有复习进度可直接继续。

单词题面在英文下方显示美式音标，词表中同样显示；来源为 [eng-to-ipa 的本地 CMU 发音词典](https://github.com/mphilli/English-to-IPA)，教材少量缺词补充及来源保存在音标服务中。无法查到的词明确显示「美式音标暂缺」，不影响练习。拼写输入有误后，输入框会自动重新聚焦，鼠标提交、回车提交及连续输错均可直接重输。

左侧进入「课内生词和短语」，选择一组或全部分组，可只练单词或短语。点击「开始复习」练完整个范围，选完意思后继续拼写；错选或首次拼写出错立即进入错题本，连续三次全部答对后移出。轮次结束后可自行再练一轮。

每次开始新训练、重新开始或再练一轮，都会随机排列所选范围内的词汇与每题选项。选择「全部词汇」时，单词和短语一起打乱；普通复习和错题专项均适用。随机结果可能偶然相同。点击「继续上次复习」保留已保存的题序、选项和进度，词表浏览顺序不变。

进度保存在本地数据库，刷新、离开或重启后可点击「继续上次复习」接着学习；拼写草稿保存在当前浏览器。重新开始仅替换当前范围的轮次，保留词条和错题记录。教材中的 sb、sth 及斜杠选用写法按词条原样填写，大小写和多余空格不影响判断。

「批量添加 / 导入」支持每行 `英文 | 中文释义`、制表符分列，以及 PDF 和 Word `.docx` 中已有的中英词表。扫描 PDF 使用本地识别；旧版 `.doc` 请先另存为 `.docx`。提取后先核对预览，可编辑、排除和调整分组，再确认入库。同组同类型的重复英文跳过，不覆盖已有记录。复杂排版或无法配对的内容可结合完整提取原文人工修正；纯图片 Word 可另存为 PDF 后导入。此流程不调用 AI。

首次启动仅导入用户照片中的 **We are all dying**（68 条）与 **Cultural childhoods**（49 条），共 117 条词汇，排除照片中其他文章和 Proper names。初始词汇只导入一次，后续删改不会被启动覆盖。

## 平时单词短语积累

左侧进入「平时单词短语积累」，按主题管理日常词汇，学习、拼写、随机出题、错题专项、自然发音和断点续练与课内板块相同。两个板块分别保存词库、分组、错题、训练轮次、筛选及拼写草稿，互不影响；可继续逐条添加或通过「批量添加 / 导入」补充。

已将 `English_notes.docx` 的 47 条笔记整理到「English notes · 日常积累」分组，共 41 个单词、9 个短语。2026-11-01 新增的第 21—47 段按独立批次补入 22 个单词、5 个短语，跨积累分组去重；已导入的批次不会再次覆盖用户编辑、恢复用户删除的词条或重置学习记录。`erosion` 更正为名词，并细化 `breach`、`would-be`、`badge`、`orient`、`entitle` 等释义，来源说明保留原文及整理理由。`utterly & completely` 拆为两个单词，`conjure up` 单列为短语；`repute` 保留名词义，原文的形容词义按本地 ECDICT 更正到 `reputed`。词表的「来源说明」可查看原文和整理说明。初始词汇仅导入一次，后续编辑或删除不会被启动覆盖。原 Word 文件保持原样，应用只需整理后的词库。

## 规格驱动开发（OpenSpec）

项目使用 [OpenSpec](https://github.com/Fission-AI/OpenSpec) 管理规格，`openspec validate --specs --strict` 全部通过：

| 能力规格 | 覆盖内容 |
|---|---|

## 技术说明

- 后端：FastAPI + SQLAlchemy(SQLite) + PyMuPDF + RapidOCR（扫描页兜底）+ httpx（OpenAI 兼容调用）
- 前端：React 18 + Ant Design 5 + ECharts（按需引入、路由级代码分割）
- 记忆算法：SM-2 简化版（认识 / 模糊 / 不认识 三档，间隔 1 → 3 → ×ease 天，间隔 ≥30 天视为掌握）
- 学习卡片支持键盘快捷键：空格翻面、1/2/3 评分

## 发音验证

安装项目依赖后，在项目根目录运行后端测试与发音播放测试（后者需 Node.js 24+）：

```powershell
backend\.venv\Scripts\python.exe -m pytest backend/tests -q
node --test frontend/tests/speech.test.mjs
cd frontend
npm run build
```

自动测试覆盖缩写、所有格和斜杠、固定声音参数、并发合并、缓存与失败重试，以及连续点击、静音、过期响应和音频地址回收。真实听感可在设置页试听，并用普通单词、完整长短语、含 sb/sth 的词条核对；首次生成后重启，再断网播放同一词条可验证本地缓存。
