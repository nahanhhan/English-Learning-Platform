# 英语学习平台

面向大学英语六级与考研英语（二）的个人英语学习工具，集翻译、写作、词汇记忆和学习统计于一体。

Windows 初次使用时先安装 Rust 工具链、Visual C++ 生成工具、Python 和 Node.js，运行 `setup.bat`。随后双击 `start.bat`，Rust 服务就绪后会自动打开学习概览。文档识别和自然发音在使用时调用本地媒体工具。

## 主要功能

| 模块 | 功能 |
|---|---|
| 学习概览 | 查看学习进度、打卡记录、练习成绩与复习任务。 |
| 真题翻译 | 按考试与年份选择题目，进行 AI 批改，查看点评、修改建议和参考译文。 |
| 短句翻译 | 进行中译英训练，支持逐句反馈、重译对比、复习清单和表达收藏。 |
| 写作练习 | 练习不同类型的作文，获取评分、逐段点评、表达建议与润色版本。 |
| 单词与短语 | 结合卡片记忆、释义测验和间隔复习学习词汇，提供词性、音标与自然发音。 |
| 课内生词和短语 | 按课文或单元管理词汇，支持释义选择、拼写训练、随机排序、错题专项和进度续练。 |
| 平时单词短语积累 | 独立整理日常词汇，支持手动添加、文档导入、学习训练及从翻译反馈中收藏表达。 |
| AI 与学习设置 | 管理不同 AI 服务，选择模型、调整支持的推理设置、测试连接，并设置学习与发音偏好。 |

学习记录与 AI 密钥保存在本机；使用 AI 批改时，作答内容会发送给所选服务。
