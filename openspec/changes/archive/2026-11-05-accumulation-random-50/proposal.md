# Why

平时积累词库逐渐增多，一轮练完全部词条耗时较长。用户希望每次练习从题库随机抽取 50 个单词或短语，使单轮题量稳定，并继续使用原来的筛选、选择释义、拼写和断点续练流程。

# What Changes

- 平时积累新轮次从当前分组、类型和练习来源的候选词条中等概率、不放回抽取最多 50 条，并随机排列题目和选项。
- 候选不足 50 条时全部使用；普通复习和错题专项均适用。各轮独立抽取，允许跨轮重复。
- 继续旧轮次保留原题目、选项和进度；重新开始、再练一轮重新抽题。
- 页面说明抽题数量及旧轮次的保留规则。

# Impact

仅调整积累新轮次的组题与提示，课内仍练习当前范围全部词条。不修改数据库结构、既有词条和学习记录。
