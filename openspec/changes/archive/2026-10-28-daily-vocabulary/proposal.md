# Why

平时积累的单词和短语需要独立于教材词库保存，并使用已经熟悉的选择释义、拼写、错题强化和断点续练流程。用户提供的 English_notes.docx 已有中英笔记，需要整理后直接进入新的词库，避免手动逐条录入。

# What Changes

- 新增“平时单词短语积累”导航和独立词库，复用课内训练的界面与答题逻辑。
- 分组、词条、轮次、错题及浏览器草稿与课内板块隔离；保留现有课内记录。
- 按原文整理词条、拆分并列单词、单列原文明确给出的短语，规范词性并记录来源。
- 整理后的词库随应用一次性导入，支持新增、编辑、删除、批量导入，后续删改不被启动覆盖。

# Capabilities

## New Capabilities
- `daily-vocabulary`: 平时积累词库、来源整理和独立训练。

## Modified Capabilities
- 无；课内功能保持原有行为。

# Impact

新增独立数据表、初始词库及一次性导入；将课内训练服务和接口复用到新板块，前端复用同一页面并隔离本地状态。不上传用户 Word 原件，不覆盖既有学习记录。
