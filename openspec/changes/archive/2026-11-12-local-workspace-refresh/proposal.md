# 本地启动与学习工作台

## Why

从打开启动脚本到能够使用首页存在等待。练习入口、题面、操作和反馈在各页的位置也不一致，切换练习时需要重新寻找下一步。

## What Changes

- 在平台可以接收请求后打开浏览器，减少启动时重复初始化和提前加载的依赖。
- 同机同数据对比当前 Python、优化后的 Python 和 Rust 试验版。以首次显示真实统计、筛选题面、提交拼写的浏览器耗时决定是否迁移。
- 更新九个页面的导航和布局，学习概览优先显示进度。试题列表支持键盘操作，加载失败时可以重试。
- 在按钮、练习阶段和弹层使用短缓动，并遵循系统的减少动态效果偏好。

## Capabilities

### New Capabilities

- `local-workspace` 统一定义本地启动、学习概览首屏、导航与动效反馈。

## Impact

启动脚本、后台初始化、前端共享布局和练习页面。现有 API、数据库结构及学习规则继续沿用。
