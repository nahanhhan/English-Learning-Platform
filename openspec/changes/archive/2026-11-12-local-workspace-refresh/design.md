# 本地启动与工作台设计

## Context

Windows 使用批处理启动本机服务，React 页面由同一服务提供。已有 SQLite 库包含学习记录和个性化设置。

## Goals / Non-Goals

- 打开浏览器时首页已经可以访问。真实进度加载前可以使用导航。
- 让选题、作答、批改和词汇反馈的操作位置更清楚。
- 将后台迁移决策建立在真实浏览器操作耗时上。

## Decisions

- 沿用既有数据初始化函数。启动阶段建表一次，网络批改客户端在首次调用时加载。
- 试验版只运行在数据库副本上。启动、真题列表和拼写写入由 Rust 实现，浏览器打开训练所需的其余接口沿用 Python。
- 首屏配色使用浅蓝灰背景、白底和深蓝强调色。桌面为分组侧栏，窄窗口打开导航弹层。原文与编辑区在宽窗口并排。
- 浏览器减少动态效果时停止自定义缓动和组件库动画，保留文字反馈与焦点。

## Risks / Trade-offs

- 基准用隔离的无界面 Chrome 反复执行同样的操作。默认浏览器窗口的实际打开时间会受系统状态影响。
- Rust 迁移须同时达到启动和两项交互门槛，随后在完整后台再次验证。
