# 本机测速与验证

同一台 Windows 电脑、同一份生产网页和同一份 SQLite 副本。通过命令行启动服务，收到首页的 HTTP 响应后让隔离的无界面 Chrome 打开页面。首页以真实统计可见、导航可操作为终点。浏览器已运行和需启动各测 10 次，每次重启后台。真题筛选和拼写判定各测 30 次，以题面或判定实际显示为终点。首次建库单独验证，批改验收使用模拟服务。

## 启动耗时

单位为秒。每格为中位数 / 第 90 百分位。

| 场景 | 改动前 Python | 优化后 Python | Rust 发布试验版 |
| --- | ---: | ---: | ---: |
| 浏览器已运行 · 后台就绪 | 2.19 / 2.72 | 1.89 / 2.21 | 0.54 / 0.55 |
| 浏览器已运行 · 首页可用 | 2.52 / 3.12 | 2.19 / 2.56 | 0.82 / 0.86 |
| 浏览器需启动 · 后台就绪 | 3.29 / 3.80 | 3.29 / 3.32 | 0.53 / 0.55 |
| 浏览器需启动 · 首页可用 | 4.46 / 5.03 | 4.52 / 4.55 | 1.69 / 1.74 |

## 日常操作耗时

单位为毫秒。每格为中位数 / 第 90 百分位。

| 场景 | 改动前 Python | 优化后 Python | Rust 发布试验版 |
| --- | ---: | ---: | ---: |
| 切换真题筛选 → 新题面 | 9.60 / 11.80 | 9.75 / 13.40 | 10.35 / 14.50 |
| 提交拼写 → 判定显示 | 14.75 / 19.10 | 15.70 / 18.90 | 11.90 / 16.50 |

Rust 试验版使用已初始化的库，直接提供首页、统计、真题筛选和拼写判定。练习准备所需的其他接口转给本机 Python，首页启动样本期间无需启动该辅助进程。首页统计及六级、考研翻译和图表作文的接口结果与 Python 一致；拼写测试逐轮核对完成记录。

## 迁移决定

以优化后 Python 为基线，Rust 达到首页提速至少 1 秒且 40% 的要求。筛题中位数慢 0.60 毫秒，拼写快 3.80 毫秒，两项均未达到各提速 30 毫秒且 20% 的要求。本次交付优化后的 Python，并移除试验程序、数据库副本和临时浏览器配置。

## 界面与数据验收

- 另做 10 次交替加载对比。使用同一个优化后的 Python 后台版本，保持浏览器运行并关闭浏览器缓存。从打开首页到真实统计可见，改版前为 418.87 / 448.00 毫秒，改版后为 195.47 / 209.08 毫秒（中位数 / 第 90 百分位）。改版后首个 HTML 直接引用的 JavaScript 约为 0.26 MB，改版前约为 1.18 MB。成绩图表单独加载。
- 空库一次启动抽测约 2.26 秒，包含题库初始化和首批接口验证。确认浏览器打开回调发生时首页和统计接口已可访问。空库导入 95 条积累词条、30 道短句题。
- 存量库副本验证续练、拼写保存、按键选题和跨页草稿恢复。模拟批改期间阻断状态查询，恢复网络后显示同一提交的结果。连续双击只生成一条提交。测试未调用外部 AI。
- 浏览器验证九页桌面鼠标导航、390 像素窄窗口键盘导航、弹层关闭和系统减少动态效果。检查学习概览和真题答题工作区的桌面与窄窗口布局。
- 后端 290 项测试、前端发音 12 项测试与生产构建均通过。原学习数据库仅用于只读复制。
