## MODIFIED Requirements

### Requirement: 本机 Codex 服务

系统 SHALL 提供本机 Codex 服务和 ChatGPT 登录状态，不要求 API 密钥。服务 SHALL 允许用户在平台设置中选择模型与该模型支持的推理强度，也 SHALL 提供本机默认选项；模型目录来自本机 Codex 缓存，不代表账号实际访问权限。目录中没有能力信息时 SHALL 允许用户输入模型并提示通过连接测试确认。服务 SHALL 仅读取用户配置中的默认模型而不启用外部工具配置，不将凭据写入项目，且 SHALL 支持与原有服务并存。

#### Scenario: 使用已有登录

- **WHEN** 用户选用已通过 ChatGPT 登录的本机 Codex
- **THEN** 批改使用该登录和用户选定的模型与强度，未指定时使用默认，不使用其他服务或 API 密钥

#### Scenario: 用户调整批改设置

- **WHEN** 用户选择模型和该模型支持的强度并保存
- **THEN** 后续批改和连接测试使用该设置，现有成绩、其他服务和本机 Codex 全局设置保持不变

#### Scenario: 模型强度不兼容

- **WHEN** 用户为本机目录中已知的模型选择不支持的强度
- **THEN** 拒绝保存并保留先前设置
