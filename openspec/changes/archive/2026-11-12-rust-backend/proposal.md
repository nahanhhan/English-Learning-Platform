# Rust 本地后台

## Why

平台每次双击启动都需要等待后台加载。将本地服务改为编译后的 Rust 程序，可以缩短启动路径，并让同一个进程负责网页、学习记录和批改任务。

## What Changes

- 用 Rust 提供网页、学习统计、题库、词汇训练、翻译与写作批改以及 AI 设置的接口。
- 沿用现有 SQLite 表和题库文件，增量导入内置数据，保存现有提交、词条及复习状态。
- 文档解析、OCR 和自然发音在使用时由 Rust 调用本地媒体工具。
- Windows 安装脚本构建发布版，启动脚本运行 Rust 服务并在服务就绪时打开网页。

## Capabilities

### New Capabilities

- `rust-backend` 定义本地运行入口及现有数据的兼容行为。

## Impact

Windows 启动和安装脚本、后台运行方式、数据库初始化、既有网页接口及本地媒体处理。
