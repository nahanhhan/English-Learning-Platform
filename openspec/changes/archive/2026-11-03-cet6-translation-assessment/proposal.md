# Why

用户要求六级翻译批改以应试与公开考纲为准，避免将可接受表达的替换偏好算作错误、解释过于绝对，以及用教学分项代替正式整体定档。

# What Changes

- 六级真题翻译和短句翻译共用公开考纲评分原则与五档描述，先整体定档再说明影响得分的证据。
- 明确真实错误与可选表达的边界，保留正确译法；按语境解释词义和用法，禁止无依据的绝对规则及虚构固定扣分细则。
- 补齐短句估分边界、重译纠错和维度仅作教学诊断的提示，提供可核对的评分依据。
- 建立覆盖合理变体、真实错误、漏译、反向含义和不可信指令的测试，并使用已保存服务做实际模型对照评估。

# Capabilities

## Modified Capabilities
- `practice-grading`: 六级翻译公开标准与整体定档。
- `short-translation`: 共用六级评分、可选表达不扣分及评分解释。

# Impact

调整提示词、评分说明展示和回归验证，不重评历史结果，不修改题库、复习状态或用户配置，考研翻译与写作保留各自标准。README 维持功能概览。
