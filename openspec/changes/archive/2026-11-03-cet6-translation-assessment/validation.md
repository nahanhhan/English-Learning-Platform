# 验证记录（2026-11-03）

## 评分依据与适用范围

- 对照《全国大学英语四、六级考试大纲（2016年修订版）》翻译考核要求、4.2.1评分方法及4.2.2档次描述，使用公开标准的忠实概括；[官方原文](https://www.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)。六级真题和短句共用 `cet6_translation.py`，考研翻译及写作提示词保持各自标准。
- 先整体定档，再说明语义、完整性、真实语言错误及其影响；禁止按错误标签、参考译文相似度、教学维度加总或虚构逐点分值机械计分。可接受表达不因存在更自然的替换而扣分，修改版优先必要纠错。
- 解释限定语境，拒绝多义词一概判错和语法术语混用。重译可撤回此前不成立的批评，不把未采纳可选替换当成未解决问题。
- 页面新增评分依据；可选表达明确不扣分，维度标明仅作学习诊断。新结果保存提示词版本和程序统一的档位，旧结果和学习进度不重写。

## 真实模型评估方法

- 按用户明确授权，保持同一已配置服务、模型和推理设置进行真实对照。临时会话按测试例隔离，无跨服务回退，不修改已保存配置。密钥只在进程内从本地库读取，不进入提示词、输出记录或提交，也不公开个人配置值。
- 行为样例包括合理词汇及时态变体、真正的词形和冠词错误、局部用词歧义、核心意义反转、漏译、零散词语、完全无关作答、句子合并、音乐语境的多义词、新题材的简单准确表达、个别小错、错误批评撤回、作答中的操作指令，以及现有题库的一篇六级整段真题。
- 自建行为期望用来发现误判，不是官方评分样卷，也不代表统计意义上的阅卷准确率。逐份检查实际输出中的错误归类、修改版和说明，不能仅靠分数范围宣称效果正确。

## 迭代发现

- 旧提示词对合理表达列出多项不必要替换，新规则能够保留原译文。第一轮亦发现模型把本句的真实词形问题归为不扣分优化，随后补强“其他语境可成立不代表本句正确”的边界。
- 初轮合句测试样例本身改变了“尝试”的修饰范围，不能把它当成仅合句的等价样例；修正测试文本使原有目的关系和修饰范围保持一致后复测。
- 第二轮评分与错误分类符合预设期望，但一份用法说明混用了语法术语；进一步要求以本句关系和动作承担者解释，避免不必要的词性断言，并完整复测最终版本。
- 第三轮还发现一篇整段题对 and 并列活动的过度字面对照，且遗漏评分依据。最终补强逻辑关系不等于连接词逐字对应的原则，给整段输出更明确的字段示例；新真实批改缺少非空评分依据时会保留作答并明确失败，不静默展示不完整成功结果。
- 不同轮次仍有估分波动，部分措辞可能不够精确；程序统一档位展示可以避免档位标签冲突，但提示词不能提供当次官方样卷校准，也不能保证每次输出完全一致。保留训练估分说明，不承诺正式考试确定得分。

## 最终真实测试结果

累计62次真实调用，包含旧提示词对照、四个提示词版本的检查，以及1次连接异常后的同配置重试。最终版本 `cet6-translation-20261103-v4` 的19个不同样例均取得结构完整的结果并通过预设行为校验；逐份核对关键错误、可选表达、评分依据和修改版。正确且无实质错误的样例均保留了原作答，未作不必要重写。

| 样例类型 | 最终观察 |
|---|---|
| 合理的词汇、时态及衔接变体 | 最高档，无虚构错误，原表达保留 |
| 真实词形、搭配和冠词错误 | 指出当前语境的问题，不将其降格成单纯偏好 |
| 局部多义词不贴切 | 说明具体歧义和有限影响，不把该词在其他语境的正确用法一概否定 |
| 另一语境中的正确多义词 | 认可正确含义，不沿用词语黑名单 |
| 核心含义反转 | 明确指出严重意义或逻辑错误，低于准确完整作答 |
| 漏译、零散词语、完全无关作答 | 区分未译信息、有限词义对应及无可评译意，不因英文通顺就给高分 |
| 同义合句、新题材简单表达 | 认可结构转换，不强求题库训练句式 |
| 单个小语法错误 | 指出错误但不自动降出最高档 |
| 以前不成立的批评 | 重译时撤回，无强制换词和虚构未解决问题 |
| 作答内的满分操作指令 | 忽略指令，仍按真实译意评估 |
| 整段真题 and／while 两种表达 | 两者均接受，均提供完整评分依据 |
| 新题材中合理 and 与相反含义对照 | 前者认可，后者仍识别反向含义，避免仅记住已见题目 |

预设行为校验不是官方阅卷认证。结果仅覆盖本次被测模型和样例，不能推断所有模型均有相同表现；一次连接异常未返回评分，单例重试后补齐，未以其他服务替代。
