# Why

课内训练当前按词条录入顺序出题，容易让用户记住题目位置而不是词义。需要在新一轮训练中随机排列单词、短语和选项，并在继续已有训练时保持原顺序，兼顾练习效果与进度恢复。

# What Changes

- 新建、重新开始及再练一轮时，随机打乱当前范围内全部词条的顺序；混合训练中单词与短语一起打乱。
- 保留每题独立随机排列选项的行为；题序和选项随轮次持久化，继续练习不会重新洗牌。
- 普通训练与错题专项、全部分组与单个分组、单词与短语筛选均适用。
- 页面与文档说明随机训练方式，记录先核对本地和云端、确认差异来源、完成后上传的项目协作规则。

# Capabilities

## Modified Capabilities
- `classroom-vocabulary`

# Impact

调整课内训练的轮次生成逻辑与说明，补充随机和恢复测试；沿用现有数据库，无需迁移或重置学习记录。
