# rust-backend 规格

## Purpose
定义 Rust 后台的本机运行入口，以及学习记录、题库、批改和媒体处理的兼容行为，让现有学习者升级后能使用原有数据继续练习。

## Requirements

### Requirement: Rust 本地服务

Windows 启动入口 SHALL 运行 Rust 程序，在本机提供现有网页和学习接口。文档解析、OCR 和语音合成 SHALL 在相应功能收到请求后调用本地媒体工具。

#### Scenario: 进入学习概览

- **WHEN** 用户完成安装后双击启动脚本
- **THEN** Rust 服务完成数据初始化并监听本机端口，随后打开学习概览

#### Scenario: 预览导入文档

- **WHEN** 用户为词库选择有效的 PDF 或 Word 文档
- **THEN** 后台返回识别出的词条供用户预览和确认

### Requirement: 学习数据与接口兼容

Rust 服务 SHALL 读写平台现有 SQLite 学习库，沿用网页接口、词条编号、复习记录和批改历史。内置题库更正和笔记词库导入 SHALL 保留既有编号及用户操作。

#### Scenario: 继续已有的拼写练习

- **WHEN** 用户使用已有 SQLite 学习库启动平台并继续一轮词汇复习
- **THEN** 可以继续原题号和答题阶段，重复请求不会再次记录完成结果

#### Scenario: 上次批改中途退出

- **WHEN** 服务重启时发现仍在等待批改的作答
- **THEN** 页面可以读取作答记录，并允许用户重新批改
