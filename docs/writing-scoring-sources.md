# 写作训练评分依据

平台的评分是依据公开资料提供的练习估分，不是考试机构公布的成绩。AI 仍可能误判，应结合具体证据查看反馈。

## 大学英语六级

- 教育部教育考试院公布的[《全国大学英语四、六级考试大纲（2016年修订版）》](https://www.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)第 4.1 节列出作文总体评分原则和五个分档。写作规则按这些描述概括，不能用逐项扣分或诊断维度之和代替整体评定。
- 分档中既有表达、连贯等要求，也描述语言错误的程度；高档允许个别小错，而特定低档的描述包含较多或严重错误。具体仍须结合全文和实际题目判断。

## 考研英语（二）

- 教育部教育考试院公布的[2017 年硕士研究生招生考试英语（二）考试大纲](https://yankao.neea.edu.cn/html1/report/16103/1374-1.htm)提供考试要求；题型各自独立评估。
- 应用文和短文的分档及语言评价参考清华大学出版社公开的[考纲解读与评分标准](https://www.tup.tsinghua.edu.cn/upload/books/yz/103886-02.pdf)。这是一份公开出版的解读资料，不是本平台取得的当次官方阅卷细则或评分样卷。实际考试应以当年考试主管部门公布的要求和阅卷依据为准。

平台不能取得或复现每次考试的内部评分样卷，因此不能保证训练估分与当次真实阅卷完全一致。规则版本只标识平台采用的训练规则，不代表官方发布了该版本。
