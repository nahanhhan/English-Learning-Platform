# 课内英文释义与发音来源

课内英文释义使用 Princeton WordNet 3.0 的原始释义，数据从 [NLTK 发布的 WordNet 资料](https://raw.githubusercontent.com/nltk/nltk_data/gh-pages/packages/corpora/wordnet.zip)提取词形与释义并压缩。原始许可证见 `backend/data/WORDNET-LICENSE.txt`。WordNet 包含多个义项，顺序不代表与课文相符；界面提供更多义项和 Merriam-Webster 查阅入口。

原有三个课内单元中，WordNet 未直接收录的 sheerly、absent-mindedly、-tempered、hooded、back-burner 根据对应 Merriam-Webster 词条改写，界面标注并链接来源。自定义单词未收录时显示暂无释义，不推测内容。

sake 目的义的美式音频由 en-US-JennyNeural 以 -5% 语速朗读“for the sake of”，使用单词边界截取 sake，避免脱离上下文时读作日本清酒。
